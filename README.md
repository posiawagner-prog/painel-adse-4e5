# ADSE — Painel 4º e 5º Ano

Painel da Avaliação Diagnóstica do Sistema Estadual (ADSE) para **4º e 5º anos** — Língua Portuguesa e Matemática.

## Abrir online

- Início: https://posiawagner-prog.github.io/painel-adse-4e5/
- Painel de aprendizado: https://posiawagner-prog.github.io/painel-adse-4e5/painel-aprendizado.html

Funciona no computador e no celular (barra de navegação inferior no mobile).

## Períodos

- Diagnóstica
- Formativa / Percurso
- Saída

## Atualizar dados

1. Coloque as planilhas `.xlsx` na pasta do projeto.
2. Rode `python build-dados.py`
3. Faça commit e push do `dados.js` atualizado.
